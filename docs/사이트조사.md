## 2단계 확인 결과 (실제 페이지 구조)

| 사이트 | 수집 방식 | 결과 |
|---|---|---|
| 위비티 | 목록 `?c=find&s=1&gub=1&cidx={19,21,23}&gbn=list&mode={ing,future}&gp=N` → 상세 `?c=find&s=1&gbn=viewok&ix=N` | 서버 HTML. 분야·응모대상·주최·접수기간·상금·홈페이지가 표(`ul.cd-info-list`)로 나옴 |
| 콘테스트코리아 | 목록 `list.php?displayrow=50&int_gbn=1&Txt_bcode={코드}&Txt_sortkey=a.str_aedate&Txt_sortword=asc&page=N` → 상세 `view.php?...&str_no=N` | 서버 HTML. 상세 표(`th/td`)에 참가대상·접수기간·시상내역. 목록 날짜에는 연도가 없어 상세 페이지 필요 |
| itch.io | `/jams/in-progress?page=N`, `/jams/upcoming?page=N` | 목록만으로 충분 (제목, 주최, 시작 시각+기간 또는 마감 시각, 참가자 수). 참가자 50명 미만·120일 넘게 열린 상시 잼은 제외 |
| **씽굿** | — | **보류.** 목록은 자바스크립트가 검색 조건을 암호화(CryptoJS)해서 요청하고, 상세 페이지도 암호화된 `querystr`로만 열림 (`contest_pk`로 열면 "없는 게시글" 안내 후 목록으로 이동). sitemap.xml에도 공모전 페이지가 없음. 암호화를 풀어 요청하는 방식은 사이트가 의도한 접근 방식을 우회하는 것이라 쓰지 않는다. 씽굿 공모전 상당수는 위비티·콘테스트코리아에도 올라오므로 우선 이 두 곳으로 대신하고, 필요하면 씽굿에 제휴·데이터 제공을 문의 |

## 공통 수집 규칙
- 요청 간격 3초 이상 (위비티가 GPTBot에 3초를 요구하므로 모든 사이트에 같은 값 적용)
- User-Agent: `ContestHubBot/0.1 (+사이트 주소; 연락처 이메일)` — 연락처는 발주자에게서 받은 뒤 넣는다
- 첨부파일(pdf, hwp, zip 등)은 받지 않는다. 본문 텍스트와 링크만 저장
- 공모전 본문 전체를 사이트에 다시 올리지 않는다 (작업지시서 7장)
